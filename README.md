# 片库归档台

一个仅监听本机地址的文件夹整理工具，用于扫描视频目录、识别并清理文件名、预览批量重命名，以及刮削和保存影片资料。

## 当前能力

- 扫描最多 8 层目录，识别常见视频与字幕格式。
- 识别常规番号、FC2、1Pondo、Caribbeancom、10Musume、Pacopacomama、HEYZO、Tokyo Hot 等命名。
- 清理网址和常见广告标记；例如 `1pondo1111-111 hexjs.com.mp4` 会建议为 `1PONDO-1111-111.mp4`。
- 在扫描摘要和影片行中显示广告命中明细；勾选“隔离广告”后，将 `.url`、快捷方式和命中广告规则的杂质移到 `.media-archiver-trash`，不会永久删除。
- 自动配对同名字幕并保留 `zh-CN`、`zh-TW`、`en`、`ja` 等语言后缀。
- 执行前检查非法字符、重复目标和已有文件；不覆盖文件，失败时尽量回滚。
- 可选“重命名所在文件夹”：按文件夹模板修改当前影片目录名，但不改变上级目录；按演员归档才会移动目录层级。
- 扫描、整理和刮削任务提供可回看的进度日志；批量刮削会逐项记录当前番号及成功或失败原因。
- 根据刮削或手工填写的第一位演员，将完整影片文件夹归档为 `演员目录/影片目录`；缺演员、部分选择或目标冲突都会在预览中阻止执行。
- 独立“片库”页可同时索引多个来源目录，以海报卡片查看番号、标题、演员、片商、版本和重复状态，并搜索当前结果。
- 同番号先归为一部影片；同番号且同大小的候选再计算 SHA-256。内容完全一致的副本标记为重复且不自动删除，内容不同的版本以 `-V2` 等名称保留。
- 片库归集支持单独输出目录；留空时默认使用第一个来源目录下的 `整理完成`。文件处理可选复制、移动或硬链接，执行前统一预览且不覆盖已有文件。
- 通过 JavBus 刮削标题、日期、演员、制作商、系列、标签和封面。
- 保存 Kodi/Jellyfin 可读取的 `.nfo`、本工具使用的 `.media-archive.json`，并可下载封面。

## 启动

需要 Node.js 20 或更高版本，不需要安装 npm 依赖。

Windows 下可直接双击 `start.cmd`。服务启动成功后会自动打开浏览器；如果服务已经运行，则直接打开现有页面。

也可在 PowerShell 中手动运行：

```powershell
node src/server.mjs
```

浏览器打开 [http://127.0.0.1:4318](http://127.0.0.1:4318)。服务只绑定 `127.0.0.1`，不会监听局域网地址。

运行测试：

```powershell
npm.cmd test
```

## 使用顺序

1. 点击“浏览”在页面内选择目录，或直接输入下载目录；设置扫描深度后扫描。
2. 在表格中核对识别番号和目标文件名；未识别项目可直接手工补番号。
3. 修改番号后可点击旁边的 `+`，将这次修正保存为精确匹配或正则矫正规则，并选择是否重新扫描、回溯应用当前批次。
4. 在“命名配置”页设置视频、字幕和文件夹模板、广告关键词及演员目录模板；页面会优先使用当前扫描批次实时预览。
5. 选择项目，按需勾选“隔离广告”或“按演员归档”，再打开“预览整理”。重命名、隔离与目录移动会一起检查冲突，确认后才执行。
6. 打开右侧影片资料，在线刮削或手工补全后保存 NFO、JSON 和封面。
7. 切换到“片库”，添加一个或多个来源目录；按需设置输出目录，并选择复制、移动或硬链接。
8. 刷新片库后勾选影片并打开“预览归集”。确认演员目录、变体名称、重复跳过和错误项后再执行可用项。

项目内置了 `demo-library` 示例目录，可直接选择并扫描或添加到片库。里面有广告后缀、缺字幕、无法自动识别、多段影片、演员资料和 `-FHP` 同内容重复文件等情形；所有 `.mp4`、`.mkv` 都是极小文本占位文件，只用于测试扫描，不能播放。

命名配置保存在 `.media-archiver/settings.json`。可用变量包括 `{code}`、`{part}`、`{title}`、`{actor}`、`{studio}`、`{year}`、`{lang}`、`{ext}` 和 `{original}`。视频与字幕模板必须包含 `{ext}`，演员目录模板必须包含 `{actor}`。

## 设计边界

- 整理页的演员归档只允许移动到当前扫描根目录内；片库页可指定独立输出目录。跨盘“移动”会采用复制成功后删除源文件，硬链接只能选择同一磁盘卷。
- 完全重复只会在归集预览中跳过，不会自动删除源文件。输出目录位于来源目录内部时会从后续索引中排除，避免循环扫描。
- JavBus 是网页结构适配器，不是官方 API；网络不可达、站点反爬或页面改版时会返回明确错误，文件整理不受影响。
- 当前规则偏保守。低置信度和未识别项目必须人工确认，避免把普通文件名误判为番号。
- 本工具会在用户确认后改动真实文件。建议先用一个小型副本目录验证自己的命名习惯。
